# SUMMARY
The f690c017→3af5ddae rewrite touches 670 files in src/votv-coop (+33448/-56956 with -w), but after stripping ALL comments (block, line and trailing) only 141 files carry any code change at all, and about 30 of those are behaviourally interesting; the rest are dead-code deletions, header splits and log-text edits. src/votv-coop at the b150 tag ba6d8c39 is code-identical to old main f690c017 except for the single kProtocolVersion constant (150 vs 151), so "vs b150" and "vs old main" are the same audit. protocol.h is NOT a format change: with comments stripped, the only differences between 150/151/152 are the version constant and one whitespace realignment (`RedSky = 15`) — no new kinds, no struct or size changes, every static_assert size identical. But 152 is still a real wire break: commit 86d04953 changed what the interactable WireKey MEANS — doors, lights, light groups, containers, garage, appliance and door-box now address instances by a portable identity `mv_<16 hex>` both peers derive independently (new coop/element/portable_identity.cpp) instead of the game's per-process random Key, fixing the field defect where ~110 instances per world (door 31/50, light 27/42, lightgroup 27/42, container 25/56) were addressable only by the peer that minted them. The other real runtime changes are: settle-based pending-apply expiry in interactable_channel.h (25 s TTL → 5 stable index passes, 10-minute backstop), a kerfur-id release on final death (65ce2999), the power lane refusing to fall back to hardcoded offsets (cfd1d7f2), an alarm-trigger selection filter, the wisp ride released before a skippable check (07d66086), a new join Downloading/LoadingWorld phase with a byte progress bar, two diagnostics moved behind config flags (1c765b12), a grime repaint fix, and the default push-to-talk key moving from X to G. NONE of the four local fix commits is present in any form. NOTHING in the trash lane, prop_drop_intent, container contents apply, save_record_wire, remote_prop_destroy or laptop_sync changed a single line of code — every one of those files is comment-only, so BUG-1, BUG-2, BUG-017, OBS-R3Q-C01 and OBS-R3Q-P01 all still have their exact pre-existing mechanisms on 3af5ddae. There is no b151 or b152 release: no tag is reachable from 3af5ddae, the append-only ledger stops at b150, and there is no notes/b151.md or b152.md. Locally, the only build-affecting change is two new .cpp files in CMakeLists; the whole tools/ tree (including deploy-mod.ps1) was deleted and the CI gate scripts moved to .github/ci/.
